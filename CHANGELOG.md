# Changelog

## 0.3.0 — 2026-10-08

- 13 original ASCII characters, including the signature husky developer.
- Say/think, 12 personas, six themes, seeded random and structured renderBro.
- Bounded stdin, Unicode wrapping, ANSI/NO_COLOR policy and custom inert artwork.
- ESM/CommonJS/browser exports, types, coverage and archive verification.
- Default output changes; see MIGRATION.md for --plain/--box compatibility.

## 0.2.0 — 2026-10-08

- An announcement worth framing: Set `{ box: true }` or CLI `--box` to frame a multiline announcement in an ASCII box. Limits: 200 code points per line, 100 lines including the intro. Padding counts code points; wide emoji, combining marks, tabs and ANSI escape sequences may not align in every terminal.
- Add npm and CI badges to the published README.

## 0.1.1 — 2026-10-08

- No API, CLI behavior, or dependency changes.

## 0.1.0 — 2026-10-08

- Library API, CLI, mood listing, tests, documentation, and Node 22/24 CI.
