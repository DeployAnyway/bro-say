# Roadmap

## Now

The 0.3 candidate brings original characters, say/think, personas, themes, safe Unicode wrapping, stdin, deterministic random choices, structured results, dual module exports, types, a browser demo, and installed-archive verification.

## Next

Collect real terminal feedback, especially fonts, emoji widths and Windows shells. Add shell completions and community character submissions. Keep startup time and archive size budgets measured.

## Later

Explore inert community character packs, fortune input, a GitHub Action, and editor integrations. Compose with error-translator, doggo-log and ship-it-meter through pipes or public APIs. Chat integrations would require a separate explicit privacy and authentication design.

No dates or compatibility promises for experiments. Keep the core offline.
