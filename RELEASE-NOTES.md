# 1.0.0 — Build Buddy: useful summaries for real scripts

Build/test summaries, original terminal characters and Unicode speech bubbles. Emotional support for production, with receipts.

New summarizeBuild/renderBuildSummary and --summary are additive. Existing message rendering, presets, stdin and legacy layouts remain. Summary --plain is intentionally undecorated; ordinary --plain keeps its legacy behavior.

Install: `npm install @deployanyway/bro-say@1.0.0`

See README for runnable API/CLI examples, supported formats, defaults and limitations. Existing catalogs remain. Core APIs require no online services. Root demo: https://deployanyway.github.io/.

Validation is recorded in the v1 release report after final CI and installed-package verification.
